# TTA Init File Tree

This is the target shape. Application-specific directories such as `src/`, `tests/`, and package files are not generated by this Skill.

## Tracked project assets

```text
project/
├── README.md                         [MVP] project start and run instructions
├── AGENTS.md                         [MVP] shared agent rules and boundaries
├── CLAUDE.md                         [MVP] Claude Code compatibility entry
├── CONTEXT.md                        [MVP] verified domain context and vocabulary
├── .gitignore                        [MVP] local-only and temporary-file policy
├── .agents/
│   └── skills/                       [MVP when used] project-specific Skills
├── temp/
│   ├── README.md                     [MVP] temp workspace explanation
│   └── AGENTS.md                     [MVP] temp handling rules
├── docs/
│   └── adr/                          [optional] durable architecture decisions
├── assets/
│   ├── avatar/                       [optional] actual project avatar assets
│   └── images/                       [optional] actual project image assets
├── scripts/                          [optional] long-lived project automation
└── .github/
    ├── ISSUE_TEMPLATE/               [optional] GitHub issue forms
    └── pull_request_template.md      [optional] pull request checklist
```

`temp/input/`, `temp/research/`, `temp/scripts/`, `temp/reports/`, `temp/handoff/`, `temp/secrets/`, `temp/preview/`, `temp/logs/`, and `temp/cache/` are created locally as needed. Their payloads are ignored; do not create empty directories just for appearance.

## Local-only MCP assets

```text
project/
├── .agents/
│   └── mcp.json                      [when selected] local MCP source, ignored
├── .mcp.json                         native adapter, ignored when used
├── .cursor/mcp.json                  native adapter, ignored when used
├── .vscode/mcp.json                  native adapter, ignored when used
└── other tool-native MCP files       only after current support is verified
```

`.agents/mcp.json` is a local source-of-truth convention, not a universal standard that every tool reads directly. Native files are not a second human-maintained source. If no actual adapter or sync implementation exists, the Skill must say so and must not invent a command.

There is no `.tta/` requirement and no `.agents/generated/` directory.
